# WeChat Mini Program Cursor Skills

从 [wechat-mini-program-skill](https://github.com/player4sir/wechat-mini-program-skill) 生成，共 9 个技能。

在项目根执行 `node scripts/install-cursor-wechat-skills.js` 可重新安装/覆盖 SKILL.md。

## 技能列表

- **workflow-orchestrator**: Orchestrates multiple skills to complete complex tasks. Automatically chains skills for common development workflows.
- **init-project-architecture**: Initializes WeChat Mini Program global architecture with custom navigation bar calculations.
- **adaptive-color-system**: Generates professional color schemes based on project type with dark mode support.
- **generate-mock-data**: Generates realistic mock data with Chinese context and proper placeholder images.
- **generate-page**: Generates complete WeChat Mini Program pages with proper scroll-view usage, color schemes, and placeholder images.
- **generate-cloud-function**: Generates complete cloud functions with proper security, validation, and error handling.
- **database-schema-design**: Designs optimized database schemas with proper indexes, permissions, and relationships.
- **performance-optimizer**: Analyzes and fixes performance issues including setData optimization and list virtualization.
- **diagnose-and-fix**: Intelligently diagnoses errors and provides targeted fixes.
